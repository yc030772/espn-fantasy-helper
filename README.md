# Fantasy Basketball 助手(ESPN H2H 9-Cat)

純靜態網頁,沒有後端。ESPN 的 API 開放 CORS,聯盟資料由瀏覽器直接抓。

- **選秀**:依 9-cat z-score 排名。前幾輪拿最好的人,陣容成形後自動改成補弱項(等於幫你 punt)。
- **交易**:選好送出/得到的球員,直接看「對上這隊 9 類贏幾類」的前後變化,附 1 換 1 自動推薦。
- **總分表**:451 名球員的加權總分,每一類別的貢獻分開列,可排序、可下載 CSV。
- **FA**:排除所有已被選走的球員,依你隊上最弱的類別加權排序,並列出可以 drop 的人。

## 為什麼權重不是全部 1.0

各項數據尺度不同(PTS 25 分 vs BLK 1.2 顆),所以先做 **z-score 標準化** — 換算成「離聯盟平均幾個標準差」,這樣才能相加。

標準化之後仍然不該全給 1.0。H2H 每個類別各值一場勝負,一單位 z 的價值 = 它能把勝負翻過來的機率,
數學上 `權重 ∝ 1/σ(整隊該類別總分)`。用 10000 支隨機 13 人隊伍模擬出的 σ:

| | PTS | STL | REB | TO | AST | 3PM | FG% | BLK | FT% |
|---|---|---|---|---|---|---|---|---|---|
| σ | 3.12 | 3.25 | 3.44 | 3.51 | 3.87 | 3.93 | 4.18 | 4.21 | 4.95 |
| 1/σ 正規化 | 1.23 | 1.18 | 1.11 | 1.09 | 0.99 | 0.97 | 0.92 | 0.91 | 0.77 |

再把 TO 壓到 **0.6**:實測 TO 與 PTS 相關 −0.85、與 AST −0.86,它幾乎是純粹的用球權稅,
給滿權重等於每抽一個好球員就自己扣自己分。

最終預設:`PTS 1.25 / REB 1.10 / AST 1.00 / STL 1.20 / BLK 0.90 / 3PM 0.95 / TO 0.60 / FG% 0.90 / FT% 0.75`

權重在「總分表」分頁可直接改,或選 punt 預設組。設 0 = 棄該類別,交易頁的勝負計算會自動排除。

## ESPN 給了 2026-27 的什麼

實測 `seasons/2027` 端點(3178 人):

| 項目 | 有沒有 |
|---|---|
| 逐項數據預測(PTS/REB/AST…) | ❌ 0 筆 |
| 選秀排名 STANDARD / ROTO | ✅ 388 人 |
| ADP 平均選秀順位 | ✅ 502 人 |
| 拍賣價 auction value | ✅ 137 人 |
| 現役球隊 proTeamId(換隊後) | ✅ 全部 |

所以本站 = **2025-26 實際數據**(算戰力)+ **2026-27 排名/ADP/拍賣價/球隊**(算行情與撿便宜)。
等 ESPN 放出預測(`102027`)後,重跑 `rank.py` 就會自動接上。
